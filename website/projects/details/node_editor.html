Story about the Node.js editor

Storing the data for the About Me games in a json file instead of DynamoDB preserves the AWS Edge caching, and reduces cache refreshes.

But there are a couple of challenges with json files

  • editing json object files is a pain
  • getting the syntax correctly by hand is a struggle
  • it's difficult to keep track of which entries I've already made

To help overcome these challenges, I created a simple Node.js page that helps me perform the basic CRUD functions on the json files, with Copilot's help!
This has been such a time saver, we created helpers for all the games!
